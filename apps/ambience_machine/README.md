# Ambience Machine

Windows, Android, Linux. Built on `app_shell`, `audio_kit`, `chip_synth`
and `fx_kit`.

- Up to 8 layers: recordings/samples (looped with a crossfade so the seam
  can't be heard), slow random notes from a Sound Lab sound, a Waveform
  Painter wave or a soft pad (scale, range, notes per minute, note length),
  or built-in wind, rain, waves and rumble.
- Every layer drifts on its own slow random paths (volume, pan, tone,
  pitch); set how much and how fast.
- Effects on everything (shared effect editor), master volume.
- Scenes save to the Asset Locker; loading one crossfades (8 s).
- Sleep timer (fades over the last minute); render 30 s – 3 min to WAV.
- Android: keeps playing with the screen off (media-playback foreground
  service with a notification and a Stop button). Desktop keeps playing
  anyway.
