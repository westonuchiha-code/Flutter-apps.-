# poke_saves

Pure-Dart Pokémon boxes for the Game Boy and GBA games (Gen 1-3). It does on
the phone what the PC's `pkhelper` does with PKHeX.Core: it reads saves, takes
Pokémon out as PKHeX files (`.pk1` `.pk2` `.pk3`) and puts them back, with
the same bytes PKHeX writes. Every change returns new bytes. The package never
writes files: the caller backs up the save, writes a temp file, reads it back
and swaps it in, as the helper does.

```dart
final save = PokeSave.open(bytes, fileName: 'Pokemon - Gold Version.srm');
save!.game;          // PokeGame.goldSilver ; save.gameName == 'Gold'
save.boxes[0].slots; // List<Mon?>, 20 per Game Boy box (no gaps), 30 on GBA
save.party;          // List<Mon>
save.check();        // '' or what's wrong (checksums)
final t = save.take(0, 2);  // t.save = new save bytes, t.mon!.bytes = the .pk2
final p = save.put(0, 5, pkBytes, ext: 'pk1'); // p.reason 'converted from pk1 to pk2'
save.move(0, 0, 3, 0);      // inside one save (onto a Pokémon = swap)
mon.summary;         // the `mon` map Pokéville's box.json keeps
heldItemChoices(2);  // what the helper's `items` lists
```

## Games

Western versions only (English, French, German, Italian, Spanish).
Japanese and Korean saves are not opened.

| Game | Detected as | Notes |
|---|---|---|
| Red / Blue | `RB` (file name gives Red/Blue) | 12 boxes × 20 |
| Yellow | `Yellow` | |
| Gold / Silver | `GS` (file name gives Gold/Silver) | backup copy in 5 pieces |
| Crystal | `Crystal` | |
| Ruby / Sapphire | `RS` | |
| Emerald | `Emerald` | |
| FireRed / LeafGreen | `FireRed` (PKHeX's default; file name gives LeafGreen) | |

Emulator RTC footers are kept. 64 KB GBA saves (Ruby/Sapphire on some
emulators) are read with one save slot.

## Behaviour (as PKHeX)

- Game Boy boxes are lists: taking a Pokémon moves the rest up, a Pokémon put
  anywhere goes after the others. Every write repacks all boxes and the party,
  mirrors the current box and fixes the checksums (Gen 2: both copies). Gen 1
  box-bank checksums are not written: PKHeX doesn't, and the games don't read
  them.
- Gen 1 saves whose boxes the game hasn't set up yet: a Pokémon put into
  another box marks them as set up, so the game doesn't empty them on the
  first box change.
- GBA: the newer of the two save slots is changed in place, with fresh sector
  checksums (and the Hall of Fame / extra sectors', like PKHeX).
- Putting a Pokémon in sets its Pokédex seen/caught flags (Unown and Spinda
  details too).
- Gen 1 ↔ Gen 2 goes through PKHeX's Time Capsule conversion (catch rate ↔
  held item, Gen 2 moves forgotten). Refused: Game Boy → GBA, GBA → Game Boy,
  species a game doesn't have, items or moves a game doesn't have, Eggs to
  Gen 1, and Gen 2 Pokémon holding an item the Time Capsule can't carry.

## Tests

`dart test`. With `POKE_SAMPLES=<the cross-save folder>` the tests also use
the owner's real saves and Pokéville files (only read): every summary equals
the PC's box.json entry, Gold's `take` gives the exact file PKHeX wrote,
PKHeX's pk2 → pk1 conversions in Blue/Yellow are reproduced byte for byte,
saves write back unchanged, and every Pokémon goes out and back in.

## Data

`lib/src/data/tables.g.dart` is generated by `dart run tool/gen_tables.dart
[csv folder]` from [PokeAPI](https://github.com/PokeAPI/pokeapi)'s CSV data
(species, moves, abilities, types, base stats, gender and growth rates,
experience, Gen 1/3 species numbering), © PokéAPI contributors, BSD 3-Clause
licence. The Gen 2 and Gen 3 item lists are the games' own lists, written in
the generator and spelled as PKHeX shows them so summaries match. Names are
™ Nintendo / Game Freak / Creatures.
