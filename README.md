# Flutter Apps

A collection of Flutter applications targeting:

- **Windows** — primary
- **Android** — primary
- **Linux** — secondary (best-effort)

Apps live in [`apps/`](apps/). Every push is built for Windows, Android and Linux by [GitHub Actions](.github/workflows/ci.yml).

Linux dev setup: `sudo tool/setup_linux_dev.sh`. See [`CLAUDE.md`](CLAUDE.md) for development guidelines.
