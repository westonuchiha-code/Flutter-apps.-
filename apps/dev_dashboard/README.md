# Dev Dashboard

Windows, Android, Linux. Built on `packages/app_shell`.

- **Apps:** latest CI result per app (tests, Android, Windows, Linux, release)
  and one-tap install of the newest build from GitHub Releases. Android asks
  once for "Install unknown apps".
- **Errors:** every App Shell app's error log, read from the Asset Locker.
- **Assets:** browse, preview (images, audio, text), export and delete
  everything in the Asset Locker.
- **To-do:** shared list stored in the Asset Locker, tagged per app.
