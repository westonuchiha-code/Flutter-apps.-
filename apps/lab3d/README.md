# 3D Lab

Windows, Android, Linux. Test ground for `packages/engine3d`.

- A walled courtyard (bricks, pillars, crates, a ball, a flickering torch,
  hills beyond the walls) with a spinning showcase.
- Walk (joystick on phones; WASD/arrows + mouse on PC) or orbit the
  showcase (drag, pinch/wheel).
- PS1 look by default: 240-line picture, wobbling vertices, sharp texels,
  fog. Settings switch each off, or to a clean look.
- Load a model (.glb, .gltf with embedded data, .obj) from a file or the
  Asset Locker (Models), and keep it there for other apps.
- Put any Asset Locker picture (e.g. a Texture Capture texture) on the cube
  or the floor.
- Live fps, triangles and render time: how fast your device is.
