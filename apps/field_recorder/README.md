# Field Recorder

Windows, Android, Linux. Built on `packages/app_shell` and `packages/audio_kit`.

Record with the microphone (live level, clip light, scrolling waveform,
markers, pause), then trim, mark, name and tag, and save the WAV to the Asset
Locker (Recordings) for other apps. Unsaved takes survive a crash and show
under "Unsaved". Keyboard: R record/stop, Space pause/play, M marker,
Ctrl+S save.
