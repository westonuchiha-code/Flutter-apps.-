# landscape

Vista's landscapes as a package: `generate(LandSettings)` (fractal terrain,
hydraulic erosion, presets), `skyFor` (sun, moon, colours for a time of day),
`VistaWorld.build` (the engine3d scene: land, water, sun, moon, clouds),
`LandSettings` JSON (Asset Locker kind `vista_landscape`). Used by Vista and
by Puppet Stage (landscapes as sets).
